# Programação Web - IFMG Ibirité

Projeto desenvolvido durante a disciplina de **Programação Web** do curso de **Engenharia de Controle e Automação** do Instituto Federal de Minas Gerais (IFMG) - Campus Ibirité.

## 📖 Sobre o Projeto

Este repositório reúne atividades, exercícios e projetos desenvolvidos ao longo da disciplina de Programação Web, com o objetivo de aplicar os conceitos fundamentais do desenvolvimento para aplicações web.

Os projetos abordam desde a criação de páginas utilizando HTML até a integração com APIs e desenvolvimento de aplicações utilizando JavaScript.

## 🎯 Objetivos

- Aprender os fundamentos do desenvolvimento Web;
- Desenvolver páginas utilizando HTML;
- Manipular elementos da página através do JavaScript;
- Consumir Web Services e APIs REST;
- Aplicar conceitos de programação orientada a eventos;
- Desenvolver aplicações simples voltadas ao aprendizado.

## 🚀 Tecnologias Utilizadas

- HTML5
- JavaScript (ES6+)
- Web APIs
- API do IBGE
- Fetch API

## ▶️ Como Executar

1. Clone este repositório

```bash
git clone https://github.com/Gustavo-Rodrigues01/PROGRAMACAO-WEB-IFMG-IBIRITE.git
```

2. Entre na pasta

```bash
cd PROGRAMACAO-WEB-IFMG-IBIRITE
```

3. Abra o projeto desejado.

4. Execute o arquivo `index.html` diretamente no navegador.

> Caso o projeto utilize requisições para APIs, recomenda-se executá-lo utilizando a extensão **Live Server** do Visual Studio Code.
